# 范例库

阶段 6 写样页前读一遍，阶段 7 每章开工前重读，阶段 8 检查质感时与本库并排比较。
范例用来学手法。同类页面的内容不同，构图也随之不同，不照抄本库的坐标和布局。
内容是虚构的示例企业，数字是示例数据。

## 一、合格页

`good/` 下 10 页是一份项目方案的样页，用户评审后定稿。每页列出可学的手法和已知的不足。

| 页 | 内容结构 | 可学的手法 | 已知不足 |
| --- | --- | --- | --- |
| p01 封面 | 品牌图形 | 深色底配工程图框和刻度；等轴测叠板线稿取自第 4 页的建设内容；图框标题栏写文件、版本、日期、页数 | 无 |
| p02 目录 | 导览 | 每章列出页面缩略图和页码范围，读者先看到每页的图形 | 缩略图较小；正式稿页数多时按 `solution-deck.md` 2.2 只列章 |
| p03 平台架构 | 边界与穿越 | 竖向虚线画网络边界；流程序号 1 至 5 标出数据路径；拦截叉标出原始文档停住的位置；属性带写出边界内外各有什么 | 「AI 工作台与 Skill 仓库」里的方框只写一个名称，信息密度不足；「检索」标签压在两个分区的缝上 |
| p04 建设内容 | 部件与装配 | 等轴测叠板表示叠加在现有系统之上；件号气泡与右侧明细表一一对应；引线连到分组；明细表写交付形式和详见页 | 无 |
| p05 系统接入 | 等级与上限 | 台阶高度表示操作权限由低到高；重竖线表示 AI 的上限；右侧写权限、写入、记录三项规则 | 右上方留白偏大 |
| p06 执行数据 | 来源与去向 | 三层：AI 场景、数据项、生产主线；试点场景的读取路径用蓝色实线，后续场景用虚线 | 后续场景的虚线引线交叉较多，读者不易追踪 |
| p07 应用前后 | 时间压缩 | 前后两组泳道共用一条工作日刻度；尺寸线标出 10 天和 3.5 天；差值大数卡放在右侧 | 无 |
| p08 演示界面 | 界面说明 | 原型画成界面的样子；界面注释号与右侧说明一一对应；页脚标「示意」 | 无 |
| p09 实施计划 | 主导方交接 | 工作线乘月份的矩阵；格子按主导方着色；重线画交接线；菱形评审点下方写通过标准 | 无 |
| p10 待确认事项 | 期限与影响 | 时间线上的事项卡按期限排列；下方缩略图标出受影响的页，圆点写事项序号 | 无 |

全册共有的手法：

- 每页的主图结构不同，相邻两页没有同一种构图。
- 每页有属性带、评审标准框或图例，主图下方不留空。
- 颜色只用三个语义色，图例和页眉提供方胶囊说明含义。

## 二、不合格页

`bad/` 下 5 页取自前两稿，用户评审时被否定。每页列出问题，写页时对照避开。

| 文件 | 问题 | 改法 |
| --- | --- | --- |
| `b1-layer-grid.png` | 分层架构画成等大方框的网格，每个方框只写一个名词；本期和后续只靠描边区分 | 先说出本页结构；只写名称的方框合并成列表，或补上第二项信息 |
| `b2-text-table.png` | 建设内容写成 8 行文字表格，没有图形；读者看不出各项之间的关系 | 按部件与装配画叠板图，表格作为明细表放在图旁 |
| `b3-equal-boxes.png` | 应用前后画成两排等宽方框，箭头没有标签；看不出时长差别；下半页留白 | 改为同一时间轴上的两组泳道，用尺寸线标出时长 |
| `b4-card-columns.png` | 四列卡片平铺，每列结构相同；本页与相邻页都是列表 | 按内容结构重画；确实是并列关系时，用不同信息量的分组拉开层次 |
| `b5-plain-list.png` | 待确认事项写成普通表格，没有期限和影响；下半页留白 | 按期限排在时间线上，标出确认后要更新的页 |
