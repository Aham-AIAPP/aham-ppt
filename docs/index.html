Aham PPT

把零散材料做成方案级、汇报级 PPT 的 Claude 技能。页面写成 HTML 幻灯片，网页预览确认后导出可编辑 PPTX。

在 GitHub 查看 范例库 ↗ Releases ↗
八个阶段
受众、材料、论点、骨架、页面规划、样页、逐页设计、质检，每个阶段由用户确认
按内容结构设计页面
先判断边界、装配、等级、时间压缩等结构，再选对应的画法
可编辑 PPTX
文字、方框、连线和图表导出为 PPT 里可编辑的对象，讲稿进备注
两层自动检查
网页幻灯片查排版和设计问题，PPTX 查字号、用词、术语和图例
