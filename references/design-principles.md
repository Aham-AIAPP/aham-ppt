# 版式设计原则

全部文稿类型适用。阶段 5 规划页面、阶段 6 写样页、阶段 7 写全册时使用。
本文件定构图的原则。数值见 `style-tokens.md`，元素的含义见 `style-elements.md`。

## 一、七条原则

| # | 原则 | 要求 | 检验方法 |
| --- | --- | --- | --- |
| 1 | 内容决定图形 | 先判断本页内容的结构，再为这个结构设计图形 | 遮住标题只看图形，能说出本页的结构 |
| 2 | 元素有对应内容 | 每条线、每种颜色、每个符号都对应一项内容，不加装饰图形 | 逐个元素写出它代表的内容，写不出就删 |
| 3 | 信息密度 | 一页写出对象、关系和依据三层。方框至少带两项信息，连线写标签 | 找只写一个名词的方框和没有标签的箭头 |
| 4 | 一致 | 一种颜色一个含义并配图例；同一概念全册一个名称；同组元素同一层级 | 列出单页颜色，对照色表 |
| 5 | 相邻页有变化 | 相邻两页的主图不用同一种结构 | 把全册缩略图排成一行看 |
| 6 | 质感 | 数值按 `style-tokens.md`，元素按 `style-elements.md`；线宽和明暗表达主次；视觉语言可取自客户行业 | 与范例库的合格页和客户认可过的页面并排比较 |
| 7 | 可读性底线 | 最小字号 18px（9pt）；文字不溢出、不重叠；文字与底色对比足够 | `check_slides.js` 查字号、溢出、重叠和对比度，截图逐页看 |

第 7 条不达标不交付。第 1 至 6 条是设计判断，按检验方法把关。

## 二、内容结构与画法

每种结构列出 2 至 3 种画法和选用条件。表外的结构按原则 1 处理：先说出结构，再找能表达它的图形。
同一份文稿有两页结构相同时，第二页换一种画法。范例见 `assets/examples/README.md`。

| 内容结构 | 判断依据 | 画法 | 选用条件 |
| --- | --- | --- | --- |
| 边界与穿越 | 数据或权限停在哪里 | 分区图：按边界分区，画穿越路径，停住处画拦截叉 | 边界两侧各有 2 个以上对象 |
| | | 剖面带：一条横向边界带，上下两侧列出能通过和不能通过的内容 | 对象少，重点是哪些内容能通过 |
| 部件与装配 | 清单项分几层叠在现有系统上 | 叠板图：等轴测叠板加件号气泡和明细表 | 3 至 5 层，每层有清单 |
| | | 层叠条：横条自下而上叠放，条内写清单项 | 多于 5 层，或清单项很多 |
| 等级与上限 | 操作按权限由低到高并有上限 | 台阶图加重竖线 | 3 至 6 级 |
| | | 刻度尺：一条横向刻度，标出各级位置和上限 | 多于 6 级，或级间距不等 |
| 来源与去向 | 数据在某环节产生并供某处使用 | 三层来源图：主线、数据项、使用方 | 有一条明确的业务主线 |
| | | 矩阵：数据项乘使用方，交点画实心点 | 没有主线，数据和使用方多对多 |
| 时间压缩 | 前后差别在时长和并行 | 双泳道：同一时间轴上两组泳道加尺寸线 | 有可以复算的分段时长 |
| | | 前后条形：两根横条比长度，条内分段 | 只有总时长 |
| 主导方交接 | 工作随时间从一方交到另一方 | 矩阵：工作线乘月份，格子按主导方着色，画交接线 | 工作线 3 条以上 |
| | | 接力条：一根时间条，按主导方分段着色 | 只有一条工作线 |
| 期限与影响 | 事项有期限并会改动其他页 | 时间线事项卡加受影响页的缩略图 | 3 至 6 项 |
| | | 表格加期限列和影响页列 | 多于 6 项 |
| 数量对比 | 几个数值比大小 | 条形图 | 3 至 12 项 |
| | | 大数字并排，每个数配一句说明 | 2 至 4 个数，量纲不同 |
| 变化趋势 | 数值随时间变化 | 折线图，线末写名称和末值 | 4 个以上时点 |
| | | 坡度图：两列数值用线相连 | 只有前后两个时点 |
| 并列 | 几项同级，没有先后 | 分组清单：按一个属性分组，组内用短行 | 多于 6 项 |
| | | 不等宽卡片：信息多的项占宽卡 | 各项信息量差别大 |
| | | 放射图：中心写共同对象，周围放各项 | 各项都围绕同一对象 |
| 先后 | 步骤有顺序 | 编号步骤链：每步写编号、名称、执行岗位、步骤类型 | 3 至 7 步 |
| | | 甘特条：阶段画成有起止的横条，可以重叠 | 阶段有时长并有重叠 |
| 导览 | 目录 | 章列表：编号、章名、一句说明、页码范围 | 多于 16 页 |
| | | 缩略图目录：每章列出页面缩略图 | 16 页以内 |

## 三、设计细则

**信息密度**

- 方框至少带两项信息，例如编号、名称和执行人。只写一个名词的方框合并成列表。
- 流程步骤卡写编号、步骤名、执行岗位和步骤类型。
- 连线写标签，说明传递的数据或调用方式。没有标签的箭头只表示先后。
- 主图区的连续空白不超过主图区的四分之一。空白多时补属性带，或与相邻页合并。
- 放不下时拆页，不缩字号。

**颜色和线**

- 页面用了颜色、加粗、虚线、灰底这类标记，本页就要有图例，或在子标题写明含义。
- 重线只画边界、上限和交接。细线画结构，主次靠线宽和明暗拉开。
- 封面和章节页可以用深色底，正文页用白底。
- 透视、阴影、渐变和半透明不用，导出 PPTX 时会丢失或变形。等轴测线框叠板可以用。

**图形与内容**

- 不用冰山、齿轮、装饰曲线这类比喻图形。封面和结束页的品牌图形除外。
- 实物画成实物的样子：服务器画成机柜，软件界面放截图或原型。
- 视觉语言可以取自客户行业，例如制造业的工程图。可选元素见 `style-elements.md` 第六节。
