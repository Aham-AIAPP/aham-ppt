# 版式设计原则

> 全部文稿类型适用。Phase 5 规划版式、Phase 6 做样页、Phase 7 写全册时加载。
> 版式按本文件七条原则设计，不从版式库选 ID 套骨架。
> 版式库、栅格、三档主题移出主流程，文件留作参考素材，见 SKILL.md 文件表。

---

## 一、七条原则

| 序号 | 原则 | 要求 | 检验方法 |
| --- | --- | --- | --- |
| 1 | 内容决定图形 | 先判断本页内容的结构，再为这个结构设计图形 | 遮住标题只看图形，能说出本页结构 |
| 2 | 元素有出处 | 每条线、每种颜色、每个符号都对应一项内容。不加装饰图形 | 逐个元素写出它代表的内容，写不出就删 |
| 3 | 信息密度 | 一页写出对象、关系和依据三层。方框至少带两项信息，连线写标签 | 找只写一个名词的方框和无标签的箭头 |
| 4 | 一致 | 一色一义并配图例。同一概念全册一个名称。同组元素同一层级 | 脚本列出单页颜色，人工对照色表 |
| 5 | 相邻页有变化 | 相邻两页的主图不用同一种结构 | 把全册缩略图排成一行看 |
| 6 | 质感 | 数值按 `style-tokens.md`，元素按 `style-elements.md`。线宽和明暗表达主次。视觉语言可取自客户行业 | 与范例库 `assets/examples/` 的合格页和客户认可过的页面并排对比 |
| 7 | 可读性底线 | 最小字号 18px（9pt）。文字不溢出、不重叠。文字与底色对比足够 | 排版检查脚本查字号和溢出，截图逐页查重叠 |

第 7 条是底线，不达标不交付。第 1 至 6 条是设计判断，按检验方法把关。

## 二、内容结构与画法

下表每种结构给出 2 至 3 种画法和选用条件。表外的结构照样按原则 1 设计：先说出结构，再找能表达它的图形。
同一份文稿里两页结构相同时，第二页换一种画法。范例见 `assets/examples/README.md`。

| 内容结构 | 判断依据 | 画法 | 选用条件 |
| --- | --- | --- | --- |
| 边界与穿越 | 数据或权限停在哪里 | 分区图：按边界分区，画穿越路径，停住处画拦截叉 | 边界两侧各有 2 个以上对象 |
| | | 剖面带：横向一条边界带，上下两侧列出可过和不可过的内容 | 对象少，重点是哪些内容能过 |
| 部件与装配 | 清单项分几层叠在现有系统上 | 叠板图：等轴测叠板加件号气泡和明细表 | 层数 3 至 5 层，每层有清单 |
| | | 层叠条：横条自下而上叠放，条内写清单项 | 层数多于 5 层，或清单项很多 |
| 等级与上限 | 操作按权限由低到高并有上限 | 台阶图加重竖线 | 等级 3 至 6 级 |
| | | 刻度尺：一条横向刻度，标出各级位置和上限 | 等级多于 6 级，或等级间距不等 |
| 来源与去向 | 数据在某环节产生并供某处使用 | 三层来源图：主线、数据项、使用方 | 有一条明确的业务主线 |
| | | 矩阵：数据项乘使用方，交点画实心点 | 没有主线，数据和使用方多对多 |
| 时间压缩 | 前后差别在时长和并行 | 双泳道：同一时间轴上两组泳道加尺寸线 | 有可复算的时长 |
| | | 前后条形：两根横条比长度，条内分段 | 只有总时长，没有分岗位数据 |
| 主导方交接 | 工作随时间从一方交到另一方 | 矩阵：工作线乘月份，格子按主导方着色，画交接线 | 工作线 3 条以上 |
| | | 接力条：一根时间条，按主导方分段着色 | 只有一条工作线 |
| 期限与影响 | 事项有期限并会改动其他页 | 时间线事项卡加受影响页缩略图 | 事项 3 至 6 项 |
| | | 表格加期限列和影响页列 | 事项多于 6 项 |
| 数量对比 | 几个数值比大小或看趋势 | 条形图 | 比大小，项数 3 至 12 项 |
| | | 坡度图：两列数值用线连接 | 只比前后两个时点 |
| | | 大数字并排：每个数配一句说明 | 数值 2 至 4 个，量纲不同 |
| 并列 | 几项同级，没有先后 | 分组清单：按一个属性分组，组内用短行 | 项数多于 6 项 |
| | | 不等宽卡片：信息多的项占宽卡 | 各项信息量差别大 |
| | | 环形或放射：中心写共同对象，周围放各项 | 各项都围绕同一对象 |
| 先后 | 步骤有顺序 | 编号步骤链：每步写编号、名称、执行岗位、步骤类型 | 步骤 3 至 7 步 |
| | | 甘特条：阶段画成有起止的横条，可重叠 | 阶段有时长和重叠 |
| 导览 | 目录 | 章列表：编号、章名、一句说明、页码范围 | 页数多于 16 页 |
| | | 缩略图目录：每章列出页面缩略图 | 页数 16 页以内 |

## 三、设计细则

**信息密度**

- 方框至少带两项信息，如「编号、名称、执行人」。只写一个名词的方框合并成列表。
- 流程步骤卡写编号、步骤名、执行岗位和步骤类型。
- 连线写标签，说明传的数据或调用方式。无标签的箭头只表示先后顺序。
- 内容区的连续空白不超过内容区高度的四分之一。空白多时补属性带或合并两页。
- 放不下时拆页，不缩字号。

**颜色、线宽、字号、圆角**

数值按 `style-tokens.md`，全册不变。设计时决定用哪几种、画在哪里：

- 页面用了颜色、加粗、虚线、灰底这类标记，本页就要有图例，或在子标题写明含义。
- 重线只画边界、上限、交接。细线画结构，主次靠线宽和明暗拉开。
- 封面和章节页可用深色底，正文页用白底。
- 等轴测线框叠板可以用。透视、阴影、渐变、半透明不用，导出 PPTX 时会丢失或走样。

**图形与内容的关系**

- 不用冰山、齿轮、装饰曲线这类比喻图形。封面与结束页的品牌图形除外。
- 实物画成实物的样子：服务器画成机柜，界面放截图或原型。
- 视觉语言可取自客户行业，如制造业的工程图。可用的元素见 `style-elements.md` 第四节，每个元素对应一项内容。
