# Phase 3 · 核心论点提炼

入场条件：信息清单已写进基线，关键冲突已裁决。

**停等点**：完成卡同时确认信息清单和灵魂句。任何档位都单独停等。

## 步骤

**1. SCQA**：专家档由 AI 按清单直接整理；引导和教练档按 `coach-engine.md` Phase 3 序列逐步构建。

| 元素 | 要求 |
| --- | --- |
| S 情境 | 受众已知且认可的现状，1–2 句，不含判断 |
| C 矛盾 | 打破现状的事件，最好带数字或具体事件 |
| Q 问题 | 受众要做的决策，不是项目组内部的执行问题 |
| A 答案 | 明确立场，有依据，指向行动，30 字内 |

常见偏差：C 写成背景，追问「哪个事件让它必须现在处理」；A 写成摘要，追问「受众只记一件事记什么」；
Q 是执行层问题，提示「受众真正要做的决定是什么」。

**2. 灵魂句**：由 A 整理。30 字内，一句一个结论，含至少一个依据，指向预期行动。

内部评分（不展示）：有立场 30%、有依据 25%、指向行动 25%、简洁 20%。
70 分以上放行；50–69 分给修改建议后放行；50 分以下重走引导。

**3. 预期行动**：问「基于这个结论，希望受众做什么具体的事」。答案是 Phase 4 骨架的终点。

## 完成卡字段

信息清单条数（按 F/D/P/C 分列）、关键空缺、冲突裁决、SCQA、灵魂句、预期行动。
待确认：清单有没有漏掉的重要信息；灵魂句是否准确反映用户的判断。
