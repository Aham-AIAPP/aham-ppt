# 阶段 3 · 论点提炼

入场条件：信息清单已写进基线，关键冲突已裁决。

**停等点**：完成卡同时确认信息清单和灵魂句。任何档位都单独停等。

## 步骤

**1. 整理 SCQA**：专家档由 AI 按信息清单整理；引导档和教练档按 `coach-engine.md` 阶段 3 的序列逐步构建。

| 元素 | 要求 |
| --- | --- |
| S 情境 | 受众已知并认可的现状，1 至 2 句，不含判断 |
| C 矛盾 | 打破现状的事件，最好带数字或具体事件 |
| Q 问题 | 受众要做的决策，项目组内部的执行问题不算 |
| A 答案 | 明确的立场，有依据，指向行动，30 字以内 |

三种常见偏差和追问：

| 偏差 | 追问 |
| --- | --- |
| C 写成了背景 | 哪个事件让这件事必须现在处理 |
| A 写成了摘要 | 受众只记一件事时记什么 |
| Q 是执行层问题 | 受众要做的决定是什么 |

**2. 写灵魂句**：由 A 整理。30 字以内，一句一个结论，含至少一个依据，指向预期行动。

内部评分，不展示给用户：有立场 30 分、有依据 25 分、指向行动 25 分、简洁 20 分。
70 分以上放行；50 至 69 分给修改建议后放行；50 分以下重走引导序列。

**3. 确认预期行动**：以阶段 1 第 2 问的回答为起点，对照灵魂句写成一件具体的事，请用户确认或修改。
预期行动是阶段 4 骨架的终点。

## 完成卡字段

信息清单条数（按 F、D、P、C 分列）、关键空缺、冲突裁决、SCQA、灵魂句、预期行动。
待确认：清单有没有漏掉重要信息；灵魂句是否准确反映用户的判断。
