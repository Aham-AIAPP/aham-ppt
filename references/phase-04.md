# 阶段 4 · 叙事骨架

入场条件：阶段 3 已确认灵魂句和预期行动。

**停等点**：开始前不停等。完成卡输出后停等。

本阶段产出标题序列。后续阶段只改标题的措辞，不改论证结构。

## 步骤

**1. 搭论证树**

```
顶层：灵魂句
第二层：支撑论点 2 至 4 个，互不重叠，合起来足以证明灵魂句
第三层：每个论点 2 至 3 条证据，引用信息清单编号
```

- 论点从反对意见反推。引导档和教练档用阶段 3 压力测试得到的反对意见，专家档用受众卡的主要顾虑。
- 先定论证方式：归纳分组（默认，3±1 个并列论点），或演绎链（大前提、小前提、结论，最多 3 环）。
- 归纳分组的排列次序四选一：演绎、时间、结构、重要性。默认按重要性，受众最关心的在前。

**2. 写标题**：汇报类按 `wording-rules.md` 第二节写结论式标题。
方案类按 `solution-deck.md` 3.2 写名词标题加结论子标题，标题序列列成两列。

**3. 排页序**

汇报类：

```
封面 → 执行摘要 → 目录 → 章节页 → 内容页 … → 章节页 → 内容页 … → 结尾行动页
内容页数 = 总页数 − 4 − 章节数
```

方案类按 `solution-deck.md` 2.1 的章节骨架排页序，固定页组按 2.3 展开。

- 一个第二层论点一章。证据按每页 1 至 2 条分页。
- 受众主要顾虑对应的章，页数不少于其他章。
- 每页标叙事目的：impact、structure、explain、evidence、transition、action。
- 每章至少有一组现状与目标的对照页。

**4. 五项测试**

| # | 测试 | 通过条件 |
| --- | --- | --- |
| 1 | 只读标题 | 标题连读能讲清为什么做、做什么、怎么做、结果如何 |
| 2 | 互斥完备 | 同章各页不重复，合起来能证明章标题 |
| 3 | 灵魂句回溯 | 每页都支撑灵魂句，不支撑的页删去或移入附录；次要受众的每个否决点有对应页 |
| 4 | 标题检验 | 汇报类按 `wording-rules.md` 第二节检验标题；方案类检验子标题 |
| 5 | 证据配对 | 每个论点标绿（证据充分）、黄（证据偏弱）、红（没有证据） |

- AI 先改不合格的标题再测，最多 3 轮。3 轮后仍不通过的列进完成卡，由用户决定。
- 测试 5 在任何档位都做。红色论点有三种处理：补证据；降为假设并在页面写明；删除。红色项不计轮次，先处理完。

## 完成卡字段

页数和章数、论证方式和次序、第二层论点、完整标题序列（方案类含子标题）、五项测试结果。
待确认：标题序列的逻辑是否成立，有没有遗漏的论点。
