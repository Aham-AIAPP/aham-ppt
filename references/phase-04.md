# Phase 4 · 叙事骨架

入场条件：Phase 3 已确认灵魂句和预期行动。

**停等点**：无。Phase 3 刚确认过灵魂句，直接开始。

产出 Ghost Deck：只有标题序列的骨架。标题逻辑在后续阶段只改措辞，不改结构。

## 步骤

**1. 金字塔论证树**

```
顶层：灵魂句
第二层：支撑论点 2–4 个，互不重叠且合起来足以证明灵魂句
第三层：每个论点 2–3 条证据，引信息清单编号
```

- 论点优先从反对意见反推：引导和教练档用 Phase 3 压力测试找到的反对意见，专家档用受众卡的「主要顾虑」。
- 论证模式先定：归纳分组（默认，3±1 个并列论点）或演绎链（大前提→小前提→结论，最多 3 环）。
- 归纳分组的次序四选一：演绎、时间、结构、重要性（默认，受众最关心的在前）。

**2. 标题**：按 `wording-rules.md` 第二节写。方案类按 `solution-deck.md` 3.2 写名词标题加结论子标题，Ghost Deck 列两列。

**3. 页序与页数**

汇报类：

```
封面 → 执行摘要 → 目录 → 章节页 → 内容页 … → 章节页 → 内容页 … → 结尾行动页
内容页数 = 总页数 − 4 − 章节数
```

方案类按 `solution-deck.md` 2.1 的章节骨架排页序，固定页组按 2.3 展开，不套用上面的页序。

- 一个第二层论点一章。证据按每页 1–2 条折页。
- 受众主要顾虑对应的章节页数不少于其他章节。
- 每页标叙事目的：impact、structure、explain、evidence、transition、action。
- 每章至少一组「现状→目标」的对照页。

**4. 五项测试**

1. 只读标题：标题连读能讲清为什么做、做什么、怎么做、结果如何。
2. 互斥完备：同章各页不说同一件事，合起来能证明章节标题。
3. 灵魂句回溯：无论对错都不影响灵魂句的页删去或移入附录。次要受众的每个否决点有对应页。
4. 标题检验：汇报类每个标题是结论，读完知道本页核心信息。方案类标题是名词短语，检验子标题是不是结论。
5. 证据配对（任何档位都做）：每个论点标绿（证据充分）、黄（偏弱）、红（无证据）。
   红色论点补证据、降为「假设」并在页面明示，或删除。

AI 先自行修改不合格标题再测，最多 3 轮。3 轮后仍不通过的列进完成卡让用户决定。测试 5 的红色项不计轮次，必须先处理。

## 完成卡字段

页数和章数、论证模式和次序、第二层论点、完整标题序列（方案类含子标题）、五项测试结果。
待确认：标题序列逻辑是否自洽，有没有遗漏的论点。
