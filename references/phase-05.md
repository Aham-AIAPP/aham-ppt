# Phase 5 · 大纲与版式规划

入场条件：Phase 4 标题序列已确认。开始前加载 `design-principles.md`。

**停等点**：输出全部规划卡后停，等用户确认再进入 Phase 6。确认前不写任何页面。

## 步骤

**1. 确认交付模式**：向用户复述 Phase 1 定的 presenting、hybrid 或 reading，以及它对密度的影响。
presenting 页面留白多，讲稿写得多；reading 页面要能脱离讲者读懂。

**2. 逐页规划卡**

```
页码：
标题：（方案类加子标题）
叙事目的：
内容要点：（引信息清单编号）
内容结构：本页内容是哪种结构，如边界、装配、等级、来源去向、时间压缩、交接、数量对比
图形设计：为这个结构画什么图，主图占哪里，属性带和注释放哪里
参考：可空。借用了版式库或图表函数时写名称
讲稿：被挤出页面的原因、例外、举例和出处
```

- 内容结构判断按 `design-principles.md` 第二节。表里没有的结构照样写出来并设计图形。
- 聚集 3 条以上可比较的数据时画图表，不写成文字或纯表格。
- 页面文字按 `wording-rules.md` 第三节：小标题按本页内容起，不写判断句和收口。
- 一页一个信息：标题含两个可独立证伪的断言时拆页。单一结论配多条依据不拆。

**3. 全册检查**

- 相邻两页的主图结构不同。
- 「图形设计」只写「列表」或「卡片」的页，回到内容结构重新判断。确实无图形可画时写明理由。

## 完成卡字段

交付模式、规划卡页数、各内容结构的页数分布、相邻页同结构的位置（应为零）。
待确认：有没有要改的内容要点或图形设计。
