# Phase 7 · 逐页设计

入场条件：Phase 6 视觉基调已确认。`html-slides.md` 和 `design-principles.md` 已加载。

**停等点**：开始前告诉用户写页顺序和中间确认的频率，等用户说开始。

## 步骤

**1. 逐页写**：按页码顺序，每页按规划卡的内容结构和图形设计写 HTML。
坐标按内容自己定，可以偏离规划卡的草图。同类元素的尺寸和间距与样页一致。

**2. 每页写完**：运行预览和排版检查，看截图。ERROR 当页改完。

**3. 中间确认**：每 3 页给用户看一次预览（专家档每章一次）。用户有意见先改再继续。

**4. 全册预览**：全部写完后生成全册预览页，用排版检查的 `--sheet` 生成缩略图总览，检查：

- 相邻页主图结构不同。
- 同一概念全册同一名称，同一颜色全册同一含义。
- 有没有某页风格突兀。

**5. 导出**

```bash
node assets/html2pptx/html2pptx.js deck/ 交付/<文件名>.pptx --title "<标题>" --author "<作者>"
```

讲稿写在各页 `<aside>` 里，导出时进 PPT 备注。导出后有问题回到 HTML 改，不直接改 PPTX。
