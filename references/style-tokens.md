# 固定数值

> 全部文稿类型适用，Phase 5 起加载。本文件定全册不变的数值：字号、颜色、线宽、圆角、页面框架。
> 构图不在本文件里定，按 `design-principles.md` 由内容决定。元素画法见 `style-elements.md`。
> 数值取自第四稿样页的实测，代码里的同名常量在 `assets/html2pptx/components.js`，两处一致。
> 画布 1920 × 1080 像素，1px = 0.5pt。

## 一、字号

| 字号 | 用途 |
| --- | --- |
| 18px | 正文、标注、表格、页眉章名、页脚、图例。全册最小字号 |
| 20px | 方框名称、表格行名、属性带的值、提供方胶囊 |
| 22px | 分区标题 |
| 26px | 子标题 |
| 40px | 大数字 |
| 52px | 页标题 |
| 72px | 封面标题 |

- 字重只用 400、600、700 三档：600 用于方框名和表格行名，700 用于标题和数值。
- 数字、件号、序号、页码、金额用等宽字体 `Consolas, monospace`。
- 层级主要靠字重和颜色拉开。18px 正文占全册文字的大部分是正常的。

## 二、颜色

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 墨一 | `#1F2633` | 标题、方框名、数值；深色封面的底色 |
| 墨二 | `#4A5363` | 正文 |
| 墨三 | `#7D8695` | 标签、章名、页脚、次要说明 |
| 灰蓝 | `#5B6B82` | 结构主线、图框 |
| 弱灰 | `#AEB5C0` | 未选部分、后续接入、无数据 |
| 线一 | `#E3E6EB` | 分隔线、表格线 |
| 线二 | `#C9CED6` | 方框描边 |
| 底一 | `#F6F7F9` | 属性带、分区底色 |
| 底二 | `#EEF1F5` | 次级底色、图标圆底 |
| 白 | `#FFFFFF` | 页面底色 |

语义色三个，每个配一个同含义的浅底：

| 颜色 | 色值 | 浅底 | 含义 |
| --- | --- | --- | --- |
| 蓝 | `#336EE8` | `#EAF0FD` | AI：AI 执行的步骤、AI 组件、AI 场景 |
| 青绿 | `#17998A` | `#E1F3F0` | 我方服务：实施服务、驻场团队、我方主导的工作 |
| 橙 | `#D4892A` | `#FBF0DF` | 我方产品 |

- 汇报类文稿可以给三个语义色另定含义，开工时写进项目色表，全册不变。
- 项目确需第四种语义色时，写进色表并注明含义，再加进图例。
- 不用红色、渐变、半透明和单页独有的颜色。
- 「本期建设」「本客户选用」不用颜色表示：未选部分画成弱灰，或写「后续自选」。

## 三、线宽

| 线宽 | 用途 |
| --- | --- |
| 1.5px | 结构线、表格线、引线、页脚线 |
| 1.8px | 方框描边、胶囊描边、件号气泡 |
| 2.4px | 数据流箭头、选中框 |
| 3.6px | 语义重线：边界、上限、交接 |

- 重线只画边界、上限、交接三类，一页最多两处。
- 缩略图内部可用 1px。
- 虚线只表示两种含义：
  - 非本期或未发生：虚线框画后续接入的系统、后续场景，虚线连线画后续才有的数据路径。
  - 边界和参考线：网络边界、评审点竖线、对齐参考线。
- 「双方共同」「等待」这类含义不用虚线，换成浅底加实线描边或弱灰描边。

## 四、圆角与形状

- 方框 6px，卡片 8px，胶囊全圆。图框、标题栏、表格用直角。
- 不用阴影、渐变和透视。
- 等轴测线框叠板可以用：顶面用浅底，侧面用同色深色，见 `style-elements.md`。

## 五、页面框架

正文页的框架固定。框架只管页眉和页脚，主图区怎么分由内容决定。

| 位置 | 内容 | 数值 |
| --- | --- | --- |
| 左右边距 | — | 96px |
| 页眉左 | 章编号和章名，如「01　建设内容」 | 18px 墨三，top 39 |
| 页眉右 | 页间引用，如「件号 12」「接第 4 页」 | 18px 墨三，右对齐到 x=1824 |
| 标题 | 名词短语 | 52px 700 墨一，top 70 |
| 子标题 | 一句结论 | 26px 墨二，top 141 |
| 提供方胶囊 | 本页内容由哪方提供，可空 | 与子标题同一行，右对齐 |
| 主图区 | 主图、图例 | y 195–895 |
| 属性带 | 主图下方，可换成评审标准框、备注带或不放 | y 906–990，底一，圆角 6 |
| 页脚线 | — | y 1017，1.5px 线一 |
| 页脚左 | 只写示意、举例、尚未实施三类标注 | 18px 墨三 |
| 页脚右 | 页码，等宽字体 | 18px 墨三 |

封面、目录、章节页不受此框架约束，但字号、颜色、线宽仍按本文件。
